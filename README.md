# vibe-3d-printer

Bambu Lab A1 mini で物を作るための作業場。モデリングもスライスも印刷の開始も Claude がやる。

## 頼み方

Claude に欲しい物を伝えるだけ。

> 「洗面台のこの隙間に置く歯ブラシ立てが欲しい」

そのあとの流れ:

1. Claude が「ここをノギスで測って」と聞いてくるので、測って答える
2. Claude が形を作って、絵と回せる 3D プレビューを見せる
3. OK を出すと、印刷時間とフィラメント量が出る
4. ベッドが空なのを確かめて「印刷して」と言うと、Claude がクラウド経由で送信して印刷が始まる
5. 出来た物を試して「きつい」「あと 2 mm 長く」などと伝えると、直して刷り直す

## 中身

| 場所 | 役割 |
| --- | --- |
| `parts/<名前>/part.py` | 部品の形 (寸法を書いた Python)。`README.md` に実測値と印刷の記録 |
| `parts/<名前>/out/` | 生成物: プレビュー画像、3D ビューア、印刷データ `.gcode.3mf` |
| `v3d/` | 形の生成・検査・スライス・プリンタ送信の道具 |
| `printer.toml` | プリンタの機種と既定の印刷設定 |
| `scripts/studio-gui.sh` | 純正 Bambu Studio を裏の画面で動かす道具 (印刷の送信に使う) |
| `CLAUDE.md` | Claude 向けの作業手順と設計の決まり |

最初の1個は `parts/fit-test` (この機体のすき間・穴径のクセを測るゲージ) を刷るのがおすすめ。

## 新しい PC で使うとき

```
scripts/setup.sh
```
