# hood-keychain

## 目的

フードをかぶった子のアイコン絵 (`source.png`、400×400 px) を、1色刷りのキーホルダーにする。2個作る。

## 形の決め方

1. 最初に「形 (四角 / 丸 / 輪郭どおり) × 彫り方 (線だけ / 色ごとに段差)」の 6 案を陰影つきの絵で見せた。
   段差案は、フード → 髪 → 顔 → 口の順に低くして色の塗り分けの代わりにするもの。
2. 持ち主の判断は「色の塗り分けはいらない」。黒い線だけを溝にすることになった
   (紫のメッシュや頭の青い模様は、線が無いので表現しない)。
3. 線だけの 3 つの形を見せて、**丸** に決まった。

- 板: 直径 53.2 mm (絵の部分 50 mm + 縁 1.6 mm)、厚さ 2.6 mm。吊り輪込みで高さ 59.6 mm
- 線: 幅 1.0 mm の溝。底に 0.4 mm の薄皮を残す。元の絵の線は 0.6 mm 相当と細く、太さがそろって
  いるので、全体を同じだけ太らせた (`trace.thicken_evenly`)
- 口の中: 高さ 1.3 mm (cat-keychain と同じ作り)
- 金具の穴: 仕上がり径 3.5 mm、上辺の中央。絵が左右ほぼ対称なので真っすぐ吊れる (計算上の傾き 0.3°)
- 絵の四隅 (背景と、フード・服の端) は丸で切れる

`part.py` の `SHAPE` を `"square"` / `"outline"` に変えると、ほかの 2 つの形も作れる。

採寸は不要だった (相手の物に合わせる寸法が無い)。
