# bear-keychain

## 目的

黒地に白いクマの顔のアイコン絵 (`source.png`、460×460 px) を、1色刷りのキーホルダーにする。2個作る。

元の絵 `source.png` は公開の許可をもらっていないので、リポジトリには入れていない
(`.gitignore`)。作り直すには、絵を `parts/bear-keychain/source.png` に置く。

## 形の決め方

絵は白と黒の 2 階調だけ。線画ではないので、溝ではなく高さ 2 段 (段差 1.2 mm) で描き分ける。
4 案 (丸で白を盛る / 丸で白をくぼませる / 丸で白を盛って顔を 1.35 倍に / 四角で白を盛る) を
陰影つきの絵で見せて、**丸・白を盛る・アイコンどおりの配置** に決まった。

- 板: 直径 53 mm (hood-keychain とそろえた)、低い所の厚さ 1.8 mm。吊り輪込みで高さ 59.5 mm
- 白い所 (鼻づらと両目): 1.2 mm 盛り上げて、厚さ 3.0 mm。鼻づらは 22 × 26 mm、目は直径 3.7 mm
- 鼻と口: 鼻づらの中のへこみ (底は板の面)。口の線は絵のままだと 0.5 mm ほどで細すぎるので、
  1.0 mm に太らせた (`trace.thicken_thin_lines`。鼻のような太い所は変えない)
- 金具の穴: 仕上がり径 3.5 mm、上辺の中央

`part.py` の `SHAPE` / `RAISED` / `CROP` を変えると、ほかの案も作れる
(顔を大きくする案は `CROP = 340`)。

採寸は不要だった (相手の物に合わせる寸法が無い)。
