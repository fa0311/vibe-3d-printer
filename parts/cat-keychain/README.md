# cat-keychain

## 目的

持ち主が描いた猫の絵 (`source.jpg`) を、1色刷りのキーホルダーにする。
「大まかに何のキーホルダーか分かればよい」という注文。

## 形の決め方

5案 (輪郭どおりの板に線を彫る / 同じ板に線を盛る / 線画だけ / 緑の塗りの形の板に線を彫る /
丸いメダルに線を彫る) を陰影つきの絵で見比べてもらい、**輪郭どおりの板に線を彫る** 案に決まった。
口は「ただの穴だと口に見えない」との指摘で、輪郭を溝にして中を一段下げる形にした。

- 板: 幅 58.9 × 高さ 51.8 × 厚さ 2.6 mm。線の外側に 2 mm の縁
- 線: 幅 1.0 mm 以上の溝。底に 0.4 mm の薄皮を残す
- 口の中: 高さ 1.3 mm (表面から 1.3 mm 下げる)
- 金具の穴: 仕上がり径 3.5 mm、両耳の間。吊るすと約 7° 傾く (穴が重心の真上より左にあるため)

採寸は不要だった (相手の物に合わせる寸法が無い)。
