# nfc-test

## 目的

印刷の途中で NFC のチップを中に埋め込めるかを確かめる、丸い札 (そのままキーホルダーにもなる)。
うまくいったら、絵のキーホルダー (`parts/*-keychain`) にも同じやり方でチップを入れる。

持ち主の希望: 振ったときにカタカタ言わないこと。

## 実測値

持ち主がノギスで測った (2026-11-20)。チップは通販で買った丸い NFC チップで、裏に貼り付け用のテープが付いている。

| 測った所 | 値 |
| --- | --- |
| チップの直径 | 25.0 mm |
| チップの厚み (テープのはくり紙を含む) | 0.9 mm |

チップの種類 (容量など) は聞いていない。

## 決めたこと

下から順に、底 0.6 mm → チップの入る丸い空洞 (深さ 1.0 mm) → ふた 0.8 mm。全体は直径 32 mm・厚み 2.4 mm で、
金具を通す輪 (穴 3.5 mm) が付く。

- **空洞の天井を刷る直前 (高さ 1.6 mm) で一時停止する** (`PRINT` の `pause_at`。仕組みは `v3d/slicer.py` の冒頭)。
  スライス結果で、一時停止の命令がその位置に 1 個だけ入っていることを確かめてある
- 空洞の直径は 25.65 mm (チップより片側 0.3 mm ほど大きい)。熱いベッドの上で指でぽとりと置けるように、ゆるめにした
- 空洞の深さは 1.0 mm。層の境目 (0.2 mm きざみ) でしか止められないので、チップの厚み以上でいちばん近い境目。
  チップが縁から飛び出すとノズルが当たるので、浅い側には倒さない。はくり紙をはがしたチップの上には
  0.1〜0.2 mm のすき間が残り、天井の 1 層目 (宙に渡して刷る) が少し垂れてチップに乗る見込み
- カタカタ言わないように、チップは裏のテープで空洞の底に貼る。横のすき間があっても動かない
- ふたは 4 層 (0.8 mm)。1 層目は宙に渡すので荒れる。その上に 3 層重ねて表面を平らにする
- 支えなし。検査の「宙に浮いた水平な下面」の警告は空洞の天井のことで、下にチップが入るので問題ない

## 止まったときに持ち主がやること

1. 先に、スマホでチップが読めることを確かめておく (埋めたあとに読めなくなったとき、熱のせいかどうかが分かる)
2. 印刷が止まったら (開始から 9 分ほど。本体の画面と Bambu Handy に一時停止と出る)、チップのはくり紙をはがす
3. テープの面を下にして、丸いくぼみの真ん中に置き、上から軽く押して貼る。ベッドは 65℃、ノズルは 220℃ なので、
   長く触らない。チップがくぼみの縁より上に飛び出していないことを見る
4. 本体の画面か Bambu Handy で再開する

## 印刷の記録

スライス: 0.20mm Standard / Bambu PLA Basic / Textured PEI、10 分・1.8 g。一時停止は高さ 1.6 mm (9 層目の前)。
