# dog-keychain-mini

## 目的

犬耳の子のキーホルダー (`parts/dog-keychain`) の小さい版。NFC チップ入り。持ち主: 「小さい版も作りたい」(2026-11-21)。
絵の描き方とチップの入れ方は dog-keychain と同じで、そのファイルの `make()` を小さい `Size` で呼んでいる。
元の絵はリポジトリに無い (dog-keychain の README を参照)。

## 決めたこと

- 3 つの候補 (dog-keychain の README の表) から、持ち主が C を選んだ: 板の直径 30 mm、0.2 mm ノズル
  - 0.4 mm ノズルのまま 30 mm にすると、溝を 1.0 mm より細くできず、瞳がつぶれる
  - 0.2 mm ノズルなら、線も絵と一緒に細くできる (溝の幅 0.55 mm)。今の物をそのまま縮めた見た目
- 30 mm はチップ (直径 25 mm) が入る下限に近い。空洞のまわりの壁は 2.2 mm
- 厚みは dog-keychain と同じ 3.6 mm (底 0.4 + 空洞 1.0 + ふた 0.6 + 溝 1.6)
- 層は 0.1 mm (0.2 mm ノズルの標準 `0.10mm Standard`)。一時停止は高さ 1.4 mm (15 層目の前、開始から約 15 分後)
- `PRINT["nozzle"] = 0.2`: printer.toml が 0.4 mm ノズルのままだとスライスを断る (確かめた)
- 大きさ: 30.0 × 36.5 × 3.6 mm (輪込み)
