# suica-bunny

## 目的

Suica の新しいイメージキャラクター (B案の紫のうさぎ。2026-11-18 に決定、原案は世戸ヒロアキさん) の置物。
持ち主が自分で飾るためのファンメイドで、キャラクターの権利は JR 東日本にある。フィラメントは 1 色。

配布されている 3D データは見つからなかった (2026-11-20。検索エンジンと、Bambu Studio の中の MakerWorld 検索で
12 通りの言葉を試した。Printables と Thingiverse は自動アクセスを断られて見られなかった)。それで自作した。

## 参考にした絵 (リポジトリには入れていない)

- 公式の発表にある正面の絵 (平面のイラスト)。顔 (白い所・目・鼻・口) の位置と大きさは、ここから測った
- 持ち主がくれた設定画 (正面・左・背面・右の三面図つき)。体の輪郭と奥行きは、ここに合わせた

## 形の決め方

1. 最初は、正面の絵の輪郭をクッションのようにふくらませて前後に貼り合わせる形を試した。
   持ち主の判断は「そうじゃない。完全に 3D で作って欲しい。全体的にボディは丸い」。設定画をもらった。
2. どこから見ても丸い立体にするため、`v3d/blob.py` (管や柱をなめらかにつなぐ道具) を作った。
   胴体と頭は 1 本の柱、耳・腕・脚・足先は太さの変わる管で、つなぎ目を丸めてくっつけている。
3. 設定画の三面図から正面と横の影を切り出し、模型の影を重ねて、ずれている所を直した。
   重なり具合 (重なった面積 ÷ どちらかにある面積) は、正面 0.957、横 0.928。
   - 胴体: おなか (高さの 34%) がいちばん太く、胸から上はほぼ同じ太さ。横から見ると正面より少し薄い
   - 耳: 頭のてっぺんから立ち上がって外へ広がり、前へ倒れる。設定画の横向きの絵のとおり、耳の先は顔より前に出る
   - 腕: 先 (手) ほど太く、手は胴体から離れてぶら下がる。手の内側に小さなこぶ (親指)
   - 足: 左右の足先が真ん中で触れ合う。足の裏は平らに切ってある (ベッドと机に接する面)
4. 顔は 1 色なので、白い所を縁取りの溝 (幅 0.9 mm・深さ 1.0 mm) で、目・鼻・口を深い穴 (2.2 mm) で描いた。

- 大きさ: 高さ 80 mm、幅 55 mm、奥行き 34 mm (`H` を変えると、全体が同じ形で伸び縮みする)
- 自立: 計算上は立つ。刷り物の中身 (殻 + 充填 15%) で見積もった重心は高さ 37.5 mm で、足の裏
  (27 × 17.5 mm、334 mm²) の内側にある。倒れ始める傾きは、前へ 15°、後ろへ 11°、横へ 20°。後ろがいちばん弱い

採寸は不要だった (相手の物に合わせる寸法が無い)。

## 刷り方で決めたこと

立てたまま刷る (足の裏がベッド)。耳の下・手の下・股の下が宙に浮くので、支え (サポート) が要る。

- **顔の穴の天井を 45° の斜面にした。** 最初は天井が水平で、スライサーが口や目の穴の中に支えを立てた
  (取れなくなる)。斜面にしたら立たなくなった。斜面は下を向くので、見下ろすと穴は深いままに見える
- **支えは「ベッドからまっすぐ立つ柱」(`normal(auto)` + ベッドからだけ)。** 枝分かれする支え (tree) は、どの設定でも
  耳の下まで登る枝が頼りなかった:

  | 設定 | 耳の下までの枝 |
  | --- | --- |
  | tree の既定 | 1.7 × 1.0 mm の輪が 60 mm、斜めに 1 本ずつ (途切れてはいない) |
  | tree + 枝の太さ 5 mm | 高さ 18〜54 mm で、1 層あたりの線がほぼ 0 mm (針) |
  | tree_strong + 枝の太さ 5 mm | 高さ 38 mm までは直径 12 mm の幹。その上は針で、抜けている層がある |
  | tree_hybrid / tree_slim | 高さ 38 mm から上が針 |
  | normal(auto) | 12 × 11 mm ほどの柱が、ベッドから耳の下 (66 mm) まで途切れず続く |

  柱は腕と手の前に立つ。耳を前へ倒してあるので、柱は腕や手をよけてベッドまで届く。
  耳の付け根寄り (頭から 5 mm ほど) の下には柱が届かないが、頭と柱の間に渡るので刷れる見込み
- 層は 0.16 mm (丸い面の段々を目立たなくする)。足の裏だけで立つので、つば (ブリム) を付ける
- 刷り上がったら取る物: 腕の前の柱 2 本、手の下・股の下の支え、足のまわりのつば
